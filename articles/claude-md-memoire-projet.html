CLAUDE.md : le fichier qui rend Claude Code vraiment efficace

La mémoire de votre projet, en un seul fichier texte.

Publié le 23 juin 2026

Claude Code oublie tout entre deux sessions, sauf ce que vous lui écrivez noir sur blanc. Le fichier CLAUDE.md est fait pour ça : c'est la mémoire persistante de votre projet, relue automatiquement à chaque démarrage. Bien rédigé, il change complètement la qualité de ce que l'IA produit.

1. À quoi sert ce fichier, concrètement

CLAUDE.md se place à la racine de votre projet. Claude Code le charge avant toute action, ce qui lui donne le contexte qu'un humain mettrait normalement des semaines à apprendre : les conventions du code, les choix déjà faits, les pièges à éviter.

2. Ce qui mérite d'y être écrit

Les règles qui reviennent sans cesse (style de code, structure des dossiers, commandes de build ou de test), les décisions déjà tranchées pour ne pas les redébattre à chaque session, et les pièges déjà rencontrés. En gros, tout ce que vous expliqueriez à un nouveau collègue le premier jour.

3. Ce qu'il vaut mieux laisser de côté

Un CLAUDE.md trop long perd en efficacité : l'IA doit le relire en entier à chaque fois. Évitez d'y recopier une documentation déjà existante ou des détails que le code montre tout seul. Visez la synthèse, pas l'exhaustivité.

4. Un fichier qui vit avec le projet

CLAUDE.md n'est jamais terminé. Dès qu'une règle change ou qu'un nouveau piège apparaît, le bon réflexe est de le mettre à jour. Certains demandent même directement à Claude Code de proposer une mise à jour après une session productive.

5. Par où commencer

Pas besoin de viser la perfection dès le premier jet. Quelques lignes sur le projet, son fonctionnement et vos préférences suffisent pour démarrer. Le fichier s'affinera naturellement, session après session, à mesure que vous repérez ce qui vaut vraiment la peine d'être répété à l'IA.
